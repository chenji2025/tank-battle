# 坦克大战

经典坦克大战 HTML5 游戏，使用纯 HTML + CSS + JavaScript 实现，无需任何依赖。

## 游戏特点

- 玩家坦克通过键盘控制移动和射击
- 敌方坦克具有 AI 行为
- 可破坏和不可破坏的墙壁
- 多关卡系统（3关）
- 得分、生命值、关卡显示
- 爆炸特效
- 暂停功能

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 | 射击 |
| P | 暂停 |

## 如何运行

直接在浏览器中打开 `index.html` 即可开始游戏。

## 技术栈

- HTML5 Canvas
- 原生 JavaScript
- CSS3
